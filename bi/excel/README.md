# Excel: the business case model, pivot tables and Power Query

`AP_business_case.xlsx` is generated by [`scripts/build_excel_workbook.py`](../../scripts/build_excel_workbook.py).
Every result in it is a live formula, so it recalculates when an input changes.

## What is in the workbook

| Sheet | What it does |
|---|---|
| README | How to use it, colour code, the rules kept from the analysis |
| Inputs | **Scenario switch** (yellow: Worst, Base, Best), every assumption with its worst, base and best value and source, the measured € figures, the day rates |
| Levers | Each fix: € at stake, share removed, € benefit, one-off and running cost |
| Cash flow | Years 0 to 3, NPV, ROI and payback, for hard benefits only and with estimated savings |
| Scenarios | Worst, base and best side by side, whatever the switch says |
| Sensitivity | Each assumption alone at its worst and best value, with a tornado-style chart |
| Checks | Workbook figures against the Python model. Shows **ALL OK** in the Base scenario |

Colour code: **blue** = input you may change, **black** = formula, **green** = link to another sheet,
**yellow** = the scenario switch. Formulas use named ranges (`Hard_Benefit`, `CoC`, `Ramp_Y1`, …), visible in
Formulas → Name Manager.

**First check after opening:** click *Enable Editing*, then look at the Checks sheet. Every row must say
OK and the last row ALL OK. Then try the switch on the Inputs sheet: on *Worst* the Cash flow sheet shows an
NPV of €21,040 and a payback of 23.5 months.

The workbook was verified by recalculating it in LibreOffice: 504 formulas, no errors, 33 of 33 checks OK.

## Add the pivot tables (about 20 minutes, Excel on Windows)

openpyxl can't create pivot tables or Power Query connections, so these are added in Excel. Save the result
as `AP_business_case_pivots.xlsx` next to the generated file, so a rebuild of the model never overwrites
your work.

### 1. Import the invoices with Power Query

1. **Data → Get Data → From File → From Text/CSV**, choose `bi/data/invoices.csv`.
2. In the preview: *File Origin* **65001: Unicode (UTF-8)**, *Delimiter* **Comma**. Click **Transform Data**.
3. In the Power Query editor, set the types:
   - `amount`: right-click → **Change Type → Using Locale…** → *Decimal Number*, locale **English (United States)**.
     (In a German-locale Excel, skipping this turns 2122.75 into 212275.)
   - `invoice_date`, `paid_date`, `due_date`, `discount_date`: **Using Locale…** → *Date*, **English (United States)**.
   - `has_po`, `is_paid`, `paid_on_time`, `discount_taken`: *True/False*.
4. Rename the query to `Invoices`. **Home → Close & Load To… → Table**, new worksheet, and tick
   **Add this data to the Data Model**.
5. Repeat for `bi/data/leakage_by_invoice.csv` (query name `LeakageByInvoice`; `impact_eur` as decimal using
   English (United States)).

### 2. Build four pivot tables, and check each total

Insert → PivotTable → *From Data Model* (or from the loaded table). Each pivot has a known total from
`bi/data/headline_figures.csv`; if it doesn't match, a column type is wrong (step 1.3).

| Pivot | Rows | Columns | Values | Must show |
|---|---|---|---|---|
| Spend by department and month | `department` | `invoice_month` | Sum of `amount` | Grand total **€3,699,592** |
| Hard leakage by cause | `cause` (LeakageByInvoice) | `driver` | Sum of `impact_eur` | Grand total **€73,552.87**; *No duplicate check at invoice entry* **€60,264.78** |
| PO compliance by department | `department` | `has_po` | Sum of `amount`, *Show Values As → % of Row Total* | Grand total row, TRUE column: **78.4%** |
| Discount capture by month | `paid_month` | `discount_taken` | Count of `invoice_id`, *Show Values As → % of Row Total*; filter out blank `discount_taken` | Grand total row, TRUE column: **53.4%** (610 invoices) |

Add a slicer on `department` (PivotTable Analyze → Insert Slicer) and connect it to the first, third and
fourth pivot (Report Connections).

### 3. Refresh after new data

After `python scripts/export_bi_data.py` (or a new extract, see the control plan), open the pivots file and
**Data → Refresh All**. Power Query keeps absolute file paths: on another computer, change them under
**Data → Queries & Connections → (query) → Edit → Source**.
